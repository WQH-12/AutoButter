# AutoButter

基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 的安卓小游戏资源自动获取工具。

手机连上电脑后自动完成：进秘境 → 按优先级选资源格 → 派鸡妖采集 → 探尋 → 换下一个秘境，
循环到没有可采的资源为止。Windows 10/11 x64，图形界面是 MFAAvalonia。

当前版本 **v0.1.0**。

## 功能

| 能力 | 说明 |
|---|---|
| 主任务 | 进秘境 → 选格 → 派遣 → 探尋 → 别人秘境，一条流水线跑完 |
| 优先级选格 | 7 种资源各自 0~7 分，只采分数大于 0 的格 |
| 鸡妖派遣 | 读当前数量 → 连点加号 → 回读复核 → 补差额，点击被吃不会误记配额 |
| 弹窗清理 | 「恭喜獲得」「提示」等弹窗自动处理 |
| 列表循环 | 翻页 / 刷新 / 冷却 / 重进自动处理，划不动会回主界面重来 |
| 异常恢复 | 界面漂移或网络异常时尝试回冒险主页面，多轮失败才中止任务 |

## 快速开始

1. 从 [Releases](https://github.com/WQH-12/AutoButter/releases) 下载 `AutoButter-0.1.0.zip`，
   解压到**英文路径**（例如 `D:\AutoButter`）。
2. 双击 `一键安装运行环境.bat`。它会逐项检测并只装缺的：.NET 10 运行时、
   VC++ 2015-2022 x64、Python 3.10+、`MaaFw==5.8.0`、`opencv-python-headless`、adb。
   缺系统组件时会弹 UAC；国内网络可加 `-PreferMirror` 直接走镜像源。
3. 双击 `启动AutoButter.bat`（自检 + 启动），或直接运行 `MFAAvalonia.exe`。
4. 「设置 → 设备」选中手机，点截图确认画面正常。
5. 任务队列只勾「主任务」，**手机停在冒险主页面**（或秘境列表 / 自家秘境面板）再点开始。

`config/` 和 `logs/` 首次运行时自动生成。

## 任务与选项

| 任务 | 作用 |
|---|---|
| 主任务（进秘境→选格→派遣→探尋→别人秘境） | 完整链路，日常用这个 |
| 进入淫乱秘境 | 从主页面进自家秘境 |
| 领取恭喜獲得弹窗 | 清「恭喜獲得」弹窗 |
| 选格并点击（调试用） | 单节点：按优先级选资源格 |
| 探寻列表选行（调试用） | 单节点：选他人秘境行 |
| 派遣并掠奪（调试用） | 单节点：加鸡妖 + 掠奪 |

**物品收集优先级**：云英、卷轴、玉璧、蜂蜜、饷银、枸杞、酒米各 0~7 分，0 = 不采。
默认只采酒米（7）。

**派遣模式**：

- `完整队伍优先`（默认）：凑齐目标数才派，凑不齐的资源先延后；鸡妖总数只有 1~2 时目标数自动下调。
- `有几只派几只`：不让鸡妖闲置，有多少派多少，可能少于目标数。

## 常见问题

| 现象 | 处理 |
|---|---|
| 截图全黑 | 该界面禁止截屏（FLAG_SECURE），先切到游戏主界面再截 |
| 报「Agent启动失败 / Protocol version mismatch」 | `MaaFw` 版本与包内 MaaFramework 不一致，重跑 `一键安装运行环境.bat` |
| 刚点开始就中止任务 | 开局不在冒险主页面，手动回到主页面 / 秘境列表后重试 |
| 一直卡在同一处 | 检查手机网络与游戏状态；脚本多轮恢复失败会主动中止 |
