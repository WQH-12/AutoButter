# AutoButter

寻欢大侠秘境自动采集，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 的自动化脚本。

手机（或手机上的 APK）自动完成：进秘境 → 按优先级选资源格 → 派鸡妖采集 → 探尋 →
换下一个秘境，循环到没有可采的资源为止。

两个端任选其一：

| 版本 | 跑在哪 | 怎么连 |
|---|---|---|
| 桌面版 | Windows 10/11 x64，界面是 MFAAvalonia | 手机连电脑，开 USB 调试 |
| 安卓版 | 手机本地 APK，不用连电脑 | 需要 Root 或 Shizuku |

当前版本 **v0.1.5**，到 [Releases](https://github.com/WQH-12/AutoButter/releases) 下载。

## 功能

| 能力 | 说明 |
|---|---|
| 主任务 | 进秘境 → 选格 → 派遣 → 探尋 → 别人秘境，一条流水线跑完 |
| 优先级选格 | 7 种资源各自 0~7 分，只采分数大于 0 的格 |
| 鸡妖派遣 | 读当前数量 → 连点加号 → 回读复核 → 补差额，点击被吃不会误记配额 |
| 弹窗清理 | 「恭喜獲得」「提示」等弹窗自动处理 |
| 列表循环 | 翻页 / 刷新 / 冷却 / 重进自动处理，划不动会回主界面重来 |
| 异常恢复 | 界面漂移或网络异常时尝试回冒险主页面，多轮失败才中止任务 |

## 桌面版（Windows）

### 安装

1. 下载 `AutoButter-0.1.5.zip`，解压到**英文路径**（例如 `D:\AutoButter`）。
2. 双击 `一键安装运行环境.bat`。它逐项检测、只装缺的：.NET 10 运行时、
   VC++ 2015-2022 x64、Python 3.10+、`MaaFw==5.8.0`、`opencv-python-headless`、adb。
   缺系统组件时会弹 UAC；国内网络可加 `-PreferMirror` 走镜像源。
3. 双击 `启动AutoButter.bat`（自检 + 启动），或直接运行 `MFAAvalonia.exe`。

`config/` 和 `logs/` 首次运行时自动生成。

### 开始运行

1. 手机开 USB 调试，连上电脑并授权本机。
2. 「设置 → 设备」选中手机，点截图确认画面正常。
3. 任务队列只勾「主任务」，**手机停在冒险主页面**（或秘境列表 / 自家秘境面板）再点开始。

## 安卓版（单机 APK）

资源、识别模板和 agent 全部打包在 APK 里，装上就能跑，不需要电脑。

### 安装

1. 下载 `AutoButter-0.1.5-android.apk` 安装（Android 9 / API 28 及以上，arm64 设备）。
2. 打开后授予通知权限，并把 AutoButter 加进电池优化白名单。
3. 设置 → **启动模式**：有 root 选 **Root**，没有就选 **Shizuku** 并先装好 Shizuku。
4. 回首页在权限卡里点授权：Root 弹 su 授权框，Shizuku 弹授权请求。
5. 状态显示已授权后，首次启动会解包资源，等进度完成。

> Root 模式不需要装 Shizuku；Shizuku 模式不需要 root，但每次重启手机要重新启动 Shizuku 服务。

### 后台模式（推荐）

后台模式在虚拟屏里跑游戏，AutoButter 界面可以退出，手机也能正常用。

1. 首页打开「运行模式 → 后台模式」。
2. 设置 → **后台模式分辨率**，选 **720P**（720x1600，竖屏）。
3. 「任务」里只留主任务，点开始。主任务会先 `StartApp com.jsgame.jianghu`，
   把游戏拉进虚拟屏再跑；8 秒后还没进游戏，就手动开一次游戏再点开始。
4. 运行期间不要手动把游戏切走；要停就点停止。

停在任务页按 Home 会自动缩成画中画。放大预览时界面按虚拟屏档位锁方向：
720P 竖屏档就锁竖屏，不会被转成横屏只剩中间一条。

### 前台模式

不想用虚拟屏就把「运行模式」关掉。此时游戏必须在前台，AutoButter 直接操作用户
看到的这块屏幕，手机不能锁屏、不能切到别的应用。

### 安卓端常见问题

| 现象 | 处理 |
|---|---|
| 一点开始就提示 native 加载失败 | 安装包不完整，重新下载 |
| 提示「Agent 启动失败」 | 设置里打开调试模式再跑一次，然后导出日志 |
| 提示「当前是前台模式，请先切换到后台模式」 | 首页把运行模式切成后台 |
| 提示「虚拟屏幕启动失败」 | 启动模式没授权，回首页重新授权 |
| 画面比例不对 / 点击偏移 | 后台模式分辨率选 720P，并关掉系统「智能分辨率」 |
| 更新后还是旧资源 | 设置 → 项目资源 → 重新解压资源，或清除 AutoButter 数据 |
| 没有 Root 也不想装 Shizuku | 这个外壳用不了，换桌面版 |

## 任务与选项

| 任务 | 作用 |
|---|---|
| 主任务（进秘境→选格→派遣→探尋→别人秘境） | 完整链路，日常用这个 |
| 进入淫乱秘境 | 从主页面进自家秘境 |
| 领取恭喜獲得弹窗 | 清「恭喜獲得」弹窗 |
| 选格并点击（调试用） | 单节点：按优先级选资源格 |
| 探寻列表选行（调试用） | 单节点：选他人秘境行 |
| 派遣并掠奪（调试用） | 单节点：加鸡妖 + 掠奪 |

**物品收集优先级**：云英、卷轴、玉璧、蜂蜜、饷银、枸杞、酒米各 0~7 分，0 = 不采。
默认只采酒米（7）。

**派遣模式**：

- `完整队伍优先`（默认）：凑齐目标数才派，凑不齐的资源先延后；鸡妖总数只有 1~2 时目标数自动下调。
- `有几只派几只`：不让鸡妖闲置，有多少派多少，可能少于目标数。

## 常见问题（桌面版）

| 现象 | 处理 |
|---|---|
| 截图全黑 | 该界面禁止截屏（FLAG_SECURE），先切到游戏主界面再截 |
| 报「Agent启动失败 / Protocol version mismatch」 | `MaaFw` 版本与包内 MaaFramework 不一致，重跑 `一键安装运行环境.bat` |
| 刚点开始就中止任务 | 开局不在冒险主页面，手动回到主页面 / 秘境列表后重试 |
| 一直卡在同一处 | 检查手机网络与游戏状态；脚本多轮恢复失败会主动中止 |
